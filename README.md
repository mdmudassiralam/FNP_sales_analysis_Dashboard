# FNP_sales_analysis_Dashboard


📊 Sales Analysis Dashboard | FNP

Excited to share my latest Sales Analysis Dashboard for FNP (Ferns N Petals) 🌸📊

The dashboard provides a comprehensive view of sales performance, covering:

📌 1,000 Total Orders
💰 ₹35.21 Lakh Total Revenue
🛍️ ₹3,520.98 Average Customer Spending
🚚 5.53 Days Average Delivery Time

I analyzed revenue by product category, occasion, month, product, hour, and city to identify key sales trends and business opportunities.
